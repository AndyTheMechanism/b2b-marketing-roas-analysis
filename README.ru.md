# Дашборд анализа ROAS и LTV в B2B маркетинге

## 📊 Обзор проекта
В данном репозитории представлен проект по маркетинговой аналитике, реализованный одновременно в двух инструментах (Excel + Power BI). Проект объединяет данные о производительности из **Yandex Direct** и медийные метрики из **Yandex Media Metrics** для расчета многоуровневого показателя ROAS на основе прогнозного LTV.

### Ключевые особенности:
* **Единая модель данных:** Бесшовное слияние разрозненных источников данных с помощью Power Query.
* **Прогнозный LTV:** Динамическое моделирование доходности с учетом коэффициентов удержания (Retention), маржинальности и конверсии в продажи.
* **Анализ чувствительности:** Интерактивные параметры «что-если» (What-if) для тестирования различных бизнес-сценариев и гипотез.

## 🚀 Как запустить и обновить данные
Чтобы файлы корректно работали на вашем локальном компьютере:

1. **Скачайте (Clone/Download)** данный репозиторий.
2. **Путь к данным:** Определите абсолютный путь к папке `/data` на вашем диске.
3. **Обновите путь в параметрах:**
   - В **Power BI**: Перейдите в `Transform Data` -> `Edit Parameters` и вставьте путь к папке в переменную `FolderPath`.
   - В **Excel**: Откройте редактор Power Query, найдите параметр `FolderPath` в списке запросов и обновите его значение.
4. **Обновление:** Нажмите «Обновить все» (в Excel) или «Обновить» (в Power BI), чтобы данные пересчитались автоматически.
